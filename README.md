# companion-module-1stpass-1stpass

A [Bitfocus Companion](https://bitfocus.io/companion) module for controlling [1stPass](https://1stpass.app) — a professional timecode marker and title logging app for macOS.

## Features

- Create timecode markers using button text or custom text
- Record titles in sequence
- Preset buttons for common markers (Scene Start, Scene End, Good Take, Bad Take, Note, ADR, VFX, Fix Audio, Color)
- Connection status feedback
- Custom marker colors and types

## Configuration

See [companion/HELP.md](companion/HELP.md) for setup and usage instructions.

## Development

```bash
npm install
npm run build
npm run dev   # watch mode
```
